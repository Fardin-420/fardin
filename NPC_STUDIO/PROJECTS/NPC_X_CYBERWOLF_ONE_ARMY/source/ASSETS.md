## Derived files (`source/prepared/`, regenerated by `EDIT_ENGINE/prep_assets.py`)

| File | How it is made |
|---|---|
| `cyberwolf_up.png` | Real-ESRGAN x4 **anime** model (`realesrgan-x4plus-anime`, ncnn build v0.2.5.0, CPU, 128 px tiles with 16 px overlap). Restoration only: identical drawing, cleaner line art, JPEG noise removed. 2560×2560. |
| `cyberwolf_alpha.png` | IS-Net anime segmentation (`isnet-anime.onnx`, rembg release v0.0.0) at 1024 px, snapped to the restored line art with a guided filter (r = 12). |
| `cyberwolf_bg.png`, `npc_bg.png` | Background plates: subject hole dilated, inpainted (OpenCV Telea) at 512 px, softened. Used only behind the subject for 2.5D parallax; the original background is kept everywhere it exists. |
| `npc_alpha.png` | Matte from the backlight itself (dark figure against the bright window), guided-filter refined; interior forced opaque so the shirt print is solid. |
| `logo_rgba.png` | The original logo pixels, untouched, plus a circular alpha (center 318, 309.5 px; radius 312 px, 3 px feather) measured from the gold ring. |
| `anchors.json` | Measured framing points: goggle lens centers, eye line, shirt-print box, head center, logo circle, and the keep-out box around the artist mark in the CyberWolf corner (never framed). |
