# Germany's War, 1939–1945 — a 60-second documentary built entirely from code

Vertical (1080×1920, 30 fps, exactly 1800 frames) archival-style WWII documentary. Every pixel and
every sample is generated by code: no stock footage, no image/video generators, no samples.

| Layer | How it is made |
|---|---|
| Visuals | Node.js + `node-canvas`. Each frame is a pure function `renderFrame(frameIndex)`; randomness comes only from a seeded PRNG (mulberry32, seed **1945**). |
| Maps | Real borders from `world-atlas` (countries-50m) via `topojson-client` + `d3-geo` (`geoConicConformal`, rotate `[-15,0]`, center `[0,52]`). Sides are shown **only by color**: Germany/Axis steel gray `#6b6f74`, Western Allies muted blue `#3d6fa8`, Soviet Union deep red `#a8322d`. No Nazi symbols anywhere. |
| Typography | Oswald + Libre Baskerville from `@fontsource` (WOFF converted to TTF at build time, then `registerFont`). |
| Narration | `edge-tts`, voice `en-US-AndrewNeural` (fallback `en-US-GuyNeural`), rate −5 %, with word boundaries for subtitle timing. Or your own `./narration.wav`. |
| Music + SFX | Python/numpy/scipy synthesis: detuned-saw string drones in D minor, ostinato, timpani, cello drone, piano note; 24 SFX types (heartbeat, typewriter, artillery, siren, Doppler fly-by, flak, wind, waves, fire…); convolution reverb with synthesized impulse responses. |
| Mix | Narration −16 LUFS, music −22 LUFS ducked 8 dB under the voice (sidechain), SFX per-cue levels; master normalized to **−14 LUFS**, 4×-oversampled true-peak limiter (≤ −1.5 dBTP). |
| Subtitles | Burned in by canvas (word-by-word highlight, 2–4 word chunks) + clean `subtitles.srt`. |
| Encode | ffmpeg: H.264 CRF 18 `veryfast` yuv420p (BT.709), AAC 192k 48 kHz stereo, `+faststart`. |

## Install

Requirements: **Node.js ≥ 20**, **Python ≥ 3.10**, **ffmpeg/ffprobe** on `PATH`, and network access to
`speech.platform.bing.com` for edge-tts (or supply `narration.wav`).

```bash
cd ww2_germany_60s
npm install
pip install numpy scipy soundfile edge-tts pyloudnorm
```

`canvas` ships prebuilt binaries for common platforms; otherwise install Cairo/Pango dev packages
(see the node-canvas README).

## Build

```bash
npm run build            # everything: audio, 1800 frames, master, preview, srt, contact sheet, QC
npm run preview          # renders every frame at 540x960 (fast) + audio -> out/preview_540x960.mp4
npm run frame -- 450     # one frame -> out/frames/frame_0450.png   (several: npm run frame -- 0 900 1790)
npm run audio            # narration + music + SFX + mix only -> build/audio/mix.wav
npm run qc               # re-run the quality checks on the existing master
```

A full build takes about 5 minutes on 4 cores (frames render in parallel worker processes, each
piping raw frames into its own encoder; segments are concatenated losslessly).

## Pipeline

```
src/timeline.js --dump      nominal scenes + narration text           -> build/timeline_base.json
audio/tts.py                narration lines + word timings            -> build/narration/*.wav, build/narration_timing.json
src/timeline.js --resolve   solve frame-accurate scene windows        -> build/timeline.json  (prints the sync table)
audio/synth.py              music bed + every SFX cue                 -> build/audio/music.wav, sfx.wav
audio/mix.py                ducking, loudness, true-peak limiting     -> build/audio/mix.wav
src/render.js               1800 frames -> H.264                      -> build/video.mp4
ffmpeg                      mux + preview; scripts/contact_sheet.js; scripts/qc.js
```

### Timing model (why scene windows differ slightly from the brief)

The brief's windows (3 s hook, 4 s ending…) are *nominal*. Real narration is measured, then
`resolve()` solves the scene windows so that **(1)** the film is exactly 1800 frames, **(2)** every
scene ends exactly 0.3 s after its narration line ends, **(3)** narration is never cut, and **(4)**
windows stay as close to the brief as the constraints allow. Animations are driven by normalized
scene progress and by *word times* (`s.w('invades')`), so they slow down or speed up to fit and key
moments land on the spoken word: arrows launch on "invades", France's fill lands with the metal
impact on "falls", the ring closes on "the tide turns", the music falls silent on "surrenders".
If the narration could not fit in 60 s, `tts.py` re-synthesizes at a slightly faster rate.

## Swap the narration voice

* Another edge-tts voice: `NARRATION_VOICE=en-GB-RyanNeural npm run build` (list voices with
  `edge-tts --list-voices`). Rate: `NARRATION_RATE=-10 npm run build`.
* Your own recording: put **`narration.wav`** in the project root (one take, the nine lines in order,
  with a clear pause between lines). It is split at its eight longest pauses; word timing is
  distributed by syllable count. TTS is skipped.

TTS results are cached in `build/tts_cache/` (keyed by voice, rate and text).

## Change the timeline

Everything with a time lives in **`src/timeline.js`**:

* `SCENES[i].narration` — the line (subtitles and timing follow automatically);
* `start` / `end` — nominal window; `transitionIn` — `'dip'` or `'burn'` (each gets a low boom);
* `dateCard` — `{ text, at }` (typewriter reveal + one key click per character);
* `cues` — SFX: `{ sfx, gain (dBFS peak), at | frac | fromEnd | word+offset, dur?, ... }`;
* `music` — `intensity` (0–1), `cello`, `silenceAt`, `hardCut`.

Visuals for each scene live in `src/scenes/sN_*.js` (`render(ctx, s)`; `s.t`, `s.p`, `s.w(word)`,
`s.cue(name)` give scene time, progress, word times and audio-cue times). SFX generators are the
`sfx_*` functions in `audio/synth.py`; chord progressions are in `PROG`.

## Historical notes

Only the dates and facts of the brief are used. Borders are modern (from the dataset); history is
carried by color: Germany in 1939 is shown with Austria, Czechia and East Prussia (Kaliningrad is
split from Russia for this). The Stalingrad front line and pocket are schematic.
The "70–85 million" figure is the commonly cited range for WWII deaths worldwide, as given in the brief.
